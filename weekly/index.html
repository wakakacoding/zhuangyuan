本周更新

10 月 13 日夜间，状元录做了一轮大更新。下面用几段话说清楚变了什么、去哪里看。逐条的技术记录见更新日志。

  1. 史料：更多人有了完整的传
  2. 新页面与新专题
  3. 读起来更方便
  4. 更快、更稳
  5. 还没定的事

史料：更多人有了完整的传

  • 现在有 209 位状元有完整传记（今晚第一轮结束时是 170 篇），其余 458 位是「档案卡」。新传有的取自正史本传，有的取自碑传、诗文总集里的小传；不是出自正史的，在页面顶部会提示。一览表 →搜索 →
  • 名录里每位状元的「可信度」重新核过一遍：现在 A 234 人、B 289 人、C 120 人、R 24 人。C 档（只有名录、找不到史书印证）比晚上开始时少了一半以上，主要靠《文献通考》《续资治通鉴长编》《唐才子传》等书逐科核对。史料与凡例 →
  • 全部完整传的引文和史书原文逐条对过：改掉了约 45 条张冠李戴的引文，删去或改写了几篇名人传里没有出处的说法。发现错误？提交勘误 →
  • 新增了 201 条笔记野史里的轶事，每条附原文，并标明出自正史、笔记、文集还是小说。比如王嗣宗和赵昌言在太祖面前摔跤争状元。状元轶事集 →
  • 地图上能定位的状元现在有 217 位，每个点都有史书原文作依据。籍贯和名录对不上的，标了「待考」。籍贯地图 →

新页面与新专题

  • 「状元一生」：几岁中状元、活到多少岁、中榜后又过了多少年，按朝代对比；推算的年份单独标出。状元一生 →
  • 「状元之乡」：按今天的县市排行，哪里出的状元最多，还有热力地图。人物页也会列出同县、同府的状元。状元之乡 →
  • 「状元故事线」：殉国者、宰相之路、三元及第三条路线，像翻卡片一样读。故事线 →
  • 新专题：改朝换代中的状元、三元及第、一科多魁、金榜之后的岁月。专题目录按主题分了组，每个专题都写明样本有多少人。专题 →
  • 「状元年表」一格一年，颜色表示可信度；「名录一览表」可筛选、排序、导出 Excel 能打开的表格。年表 →一览表 →
  • 「争议与待考证」把各页还没定论的问题汇在一起；「史源书目」列出本站用到的每部书，能反查哪些人引用了它。待考证 →史源书目 →

读起来更方便

  • 人物页顶部有「一句话人生」摘要；可以一键切换繁体和简体，会记住你的选择。
  • 「我的收藏」：收藏的人物存在你自己的浏览器里，可以导出，也能导入到别的设备。我的收藏 →
  • 名录和传记的数据可以下载（CSV、JSON）。数据下载 →
  • 顶部导航收拢成十项，「可视化」「工具」变成下拉菜单，手机和键盘都能用。打印人物页时会自动隐藏导航、展开出处网址。

更快、更稳

  • 字体改成按页面需要分片下载，并且不再挡住首屏：每页下载量少了约一半，手机上人物页的 Lighthouse 性能分从 61 提到 100。
  • 搜索框在你点进去时才加载全文检索，页面打开更快。搜索 →
  • 每次更新前都会自动跑一遍点击测试和无障碍检查（浅色、深色），不通过就不发布。
  • 分享人物页时，链接预览会显示这位状元自己的卡片图；搜索引擎也能读到人物的结构化信息。

还没定的事
