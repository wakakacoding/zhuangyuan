辽金元科举与状元——材料边界说明

辽、金、元三朝，本站名录共 147 人，其中完整传只有 144 人（98%）。名录不缺人，缺的是能写成四段传的材料。这篇文章用本站真实缺口数字，对照《辽史》《金史》《元史》选举与本纪原文，说明边界在哪里。

一、先看缺口

三朝合计名录 147 人，完整传 144 人，占 98%；档案卡 3 人。按朝拆开：

对照本站其他朝（构建时实算）：北宋完整传占比远高于辽金，明、清更高。辽、金、元的缺口不是网站漏做，而是正史里大量只有「放进士某某」一句，拼不出寒窗、金榜、仕途、结局四段。

二、辽：有贡举，少专传

《元史·选举志》把北方王朝的科举一笔带过：辽、金也开过科场，但风气与得人规模不能和宋比。

辽、金居北方，俗尚弓马，辽景宗、道宗亦行贡试，金太宗、世宗屡辟科场，亦粗称得士。

《元史》 卷八十一 选举一逐字核对

《金史·选举志》说得更直白：辽沿用唐进士法取人，可是仕进之路里，进士出身只占一小部分。

辽起唐季，颇用唐进士法取人，然仕于其国者，考其致身之所自，进士才十之二三耳。

《金史》 卷五十一 选举志逐字核对

本纪里常见的写法是「诏开贡举，放某人及第」。例如圣宗统和六年：

是岁，诏开贡举，放高举一人及第。

《辽史》 卷十二 本纪第十二逐字核对

本站辽代名录 56 人，完整传只有 56 人（100%），档案卡 0 人，可信度仍为 C 的 0 人。有完整传的，多半靠《辽史》本传、文学传或能对上的散见；其余多数页上只有榜年与姓名——这就是「材料上限」，不是偷懒。

目前能点开的完整传包括：高举、高正、郑云从、石用中、王熙载、吕德懋、王用极、张俭等 56 人。

三、金：科目密，传记仍不均

金承辽后，进士科目兼采唐宋而加密，女真进士还用本民族文字程文：

金承辽后，凡事欲轶辽世，故进士科目兼采唐宋之法而增损之。

《金史》 卷五十一 选举志逐字核对

若夫以策论进士取其国人，而用女直文字以为程文，斯盖就其所长以收其用。

《金史》 卷五十一 选举志逐字核对

制度上「科目得人为盛」，并不等于每人在《金史》里都有专传。本站金代名录 58 人，完整传 55 人（94.8%），档案卡 3 人，C 档 3 人；简传口径下 14 人。许多人名只能落到本纪「赐进士第」或选举志的制度叙述，写不成有事件的传。

已有完整传的例如：郑时昌、刘海、张继祖、刘文龙、刘㧑、许必、赵洞、胡砺、石琚、赵安荣等 55 人。

四、元：恢复科举晚，又分左右榜

元朝到仁宗延祐年间才正式开科：

至仁宗延祐间，始斟酌旧制而行之，取士以德行为本，试艺以经术为先。

《元史》 卷八十一 选举一逐字核对

进士分两榜，第一名赐进士及第：

蒙古、色目人作一榜，汉人、南人作一榜。第一名赐进士及第，从六品。

《元史》 卷八十一 选举一逐字核对

本站元代名录 33 人，完整传 33 人（100%），档案卡 0 人。左右榜是制度分榜，人物页「同榜关系」只与同榜配对，不把左榜与右榜混列。完整传少，同样是因为《元史》对多数进士只有廷试一句，本传或碑传对得上的才写成传。

已有完整传：杨奂、张起岩、护都答儿、忽都达儿、霍希贤、宋本、泰不华、捌剌、张益、李黼、阿察赤、笃列图、王文烨、李齐、同同、陈祖仁、拜住、普颜不花、张士坚、阿鲁辉帖木儿、王宗哲、朶烈图、文允中、薛朝晤、牛继志、侻征、王宗嗣、买住、魏元礼、宝宝、杨𫐐、张栋、赫德溥化。

五、本站怎么处理这条边界

三朝合计：完整传 144／147，简传 80，档案卡 3，可信度 C 3，字段上接近「仅放榜」的 3。做法是：

  • 有本传、墓志或可核四段事件的，写成完整传；
  • 只有薄材料的，标材料厚度为简传或维持档案卡，不在正文里虚构仕途；
  • C 档继续挂「仅见名录」，升档必须有新原文。

读辽金元人物页时，若只有榜年与一句授官，那是史料边界，不是页面残缺。全体中榜后的路径见《从中榜到结局》；同榜分榜见人物页「同榜关系」与《同科与师承》；宋元党争与左右榜对照见《宋元状元与党争》。
